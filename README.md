## 📌 About the Project

**Expense Tracker** is a beginner-friendly Python project that helps you track your day-to-day expenses right from the terminal. No internet, no database — just pure Python!

This project was built to practice Python fundamentals like **functions**, **lists**, **dictionaries**, and **loops**.

---

## ✨ Features

- ➕ **Add Expense** — Add a new expense with category, note, amount, and date
- 📋 **View All Expenses** — See a numbered list of all recorded expenses
- 💰 **Total Amount** — Calculate and display the total of all expenses
- 🔄 **Continuous Menu** — Loop-based menu for smooth user experience
- 🧹 **Clean UI** — Simple and readable terminal interface

## 🚀 How to Run

### Prerequisites
- Python 3.x installed on your system

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/codebyavneesh/Expense-Tracker.git

# 2. Navigate to the project folder
cd Expense-Tracker

# 3. Run the program
python Expence_Tracker_project.py
```
